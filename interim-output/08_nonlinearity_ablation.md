# N-HLR 非线性结构消融实验

## 1. 研究动机

原实验中，N-HLR 在 Test 上取得了最低的回忆率 MAE。以不包含词元特征的模型为例，HLR -lex 的 Test MAE 为 0.128283，N-HLR -lex 为 0.118909。然而，这两个模型之间不只存在网络结构差异：原始 HLR 和 N-HLR 还使用了不同的损失函数、优化器、训练轮数、正则化强度和模型选择方法。因此，直接比较两者不能判断 MAE 改善究竟来自非线性表示能力，还是来自训练方法的变化。

本实验增加一个训练方式与 N-HLR 对齐的线性模型，用于回答以下问题：

> 在输入、损失、优化器和模型选择规则一致时，将线性映射替换为四个 ReLU 隐藏单元，是否仍能稳定降低 Test MAE？

实验实现位于 [`08_nonlinearity_ablation.ipynb`](08_nonlinearity_ablation.ipynb)。

## 2. 对照设计

实验统一使用 **-lex** 输入，只保留三个基础输入：

\[
x_c=\sqrt{1+\text{history\_correct}},
\]

\[
x_w=\sqrt{1+\text{history\_seen}-\text{history\_correct}},
\]

以及 bias。所有模型都不使用词元特征。

实验比较三个模型：

| 模型 | \(z=\log_2\hat h\) 的结构 | 训练方式 |
| --- | --- | --- |
| Original HLR -lex | 线性 | 原项目的 HLR 损失、逐样本更新和单轮训练，仅作为参考 |
| Aligned-Linear-HLR -lex | 线性 | 与 N-HLR 对齐的损失、Adam、batch、训练轮数、梯度裁剪和 Validation 选模 |
| N-HLR -lex | 四个 ReLU 隐藏单元 | 与 Aligned-Linear 完全相同的训练规则 |

核心比较是 Aligned-Linear-HLR -lex 与 N-HLR -lex。原始 HLR -lex 用于衡量仅改变损失和训练方式可以获得多大的改善。

### 2.1 共同预测过程

两个对齐模型都输出

\[
z=\log_2\hat h,
\]

并通过相同的遗忘曲线得到半衰期和回忆率预测：

\[
\hat h=2^z,
\qquad
\hat p=2^{-\Delta/\hat h}.
\]

两者使用相同的半衰期和回忆率裁剪范围。因此，本实验中的“线性与非线性”特指从基础输入到 \(\log_2\hat h\) 的映射，而不是完整预测函数是否包含指数变换。

### 2.2 线性结构

Aligned-Linear-HLR -lex 使用

\[
z=\beta_c x_c+\beta_w x_w+b.
\]

### 2.3 非线性结构

N-HLR -lex 使用四个 ReLU 隐藏单元：

\[
z=b_2+\sum_{j=1}^{4}v_j\operatorname{ReLU}
\left(w_{cj}x_c+w_{wj}x_w+b_j\right).
\]

该结构允许不同区域使用不同的局部斜率，因此可以表示基础特征之间的分段线性非线性关系。

### 2.4 共同训练设置

两个对齐模型均使用：

- 初始权重：已有的 HLR -lex 权重；
- 损失：`MSE(p) + 0.0001 MSE(log2(h)) + 1e-6 L2`；
- 优化器：Adam；
- 学习率：0.0001；
- batch size：8192；
- 最大训练轮数：5；
- 梯度范数裁剪：10；
- 每轮计算完整 Validation MAE；
- 保存 Validation MAE 最低的 epoch；
- 三个配对随机种子：42、43、44。

Aligned-Linear 和 N-HLR 在 epoch 0 都精确表示已有的 HLR -lex 函数。N-HLR 通过恒等式

\[
\operatorname{ReLU}(z)-\operatorname{ReLU}(-z)=z
\]

实现这一初始化。抽样检查中，两种表示的最大回忆率预测差异为 \(1.11\times10^{-16}\)，最大半衰期预测差异为 \(8.53\times10^{-14}\)，均属于浮点舍入误差。

## 3. 数据和评价规则

实验沿用主流程的固定数据切分：

| Split | 行数 |
| --- | ---: |
| Train | 9,254,984 |
| Validation | 2,313,746 |
| Test | 1,285,415 |

每个模型和种子只使用 Validation 选择 epoch，随后在 Test 上评价。主指标为回忆率 MAE，同时报告 RMSE、AUC、半衰期 Spearman、预测均值和预测位于上界的比例。

## 4. 实验结果

### 4.1 Validation 训练轨迹与选定轮次

Aligned-Linear 在三个种子下均持续改善到第 5 轮，因此都选择 epoch 5。N-HLR 在种子 42 和 43 下选择 epoch 5，在种子 44 下选择 epoch 4。

| 模型 | Seed | 最佳 Validation MAE | 选定 epoch |
| --- | ---: | ---: | ---: |
| Aligned-Linear-HLR -lex | 42 | 0.118438 | 5 |
| Aligned-Linear-HLR -lex | 43 | 0.118417 | 5 |
| Aligned-Linear-HLR -lex | 44 | 0.118409 | 5 |
| N-HLR -lex | 42 | 0.117471 | 5 |
| N-HLR -lex | 43 | 0.117505 | 5 |
| N-HLR -lex | 44 | 0.117420 | 4 |

Validation 与 Test 上的模型排序一致，没有出现只在 Test 上偶然反转的情况。

### 4.2 逐种子 Test MAE

| Seed | Aligned-Linear-HLR -lex | N-HLR -lex | 线性 MAE − N-HLR MAE |
| ---: | ---: | ---: | ---: |
| 42 | 0.119925 | 0.118909 | 0.001016 |
| 43 | 0.119902 | 0.118952 | 0.000950 |
| 44 | 0.119893 | 0.118847 | 0.001047 |
| **均值** | **0.119907** | **0.118903** | **0.001004** |

三个配对种子中，N-HLR 的 Test MAE 均低于 Aligned-Linear。差值位于 0.000950–0.001047，方向和数量级较稳定。

### 4.3 Test 指标汇总

| 模型 | MAE | MAE 标准差 | RMSE | AUC | Spearman(h) | 平均预测 | 上界预测比例 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Original HLR -lex | 0.128283 | — | 0.290873 | 0.537459 | 0.160552 | 0.962699 | 34.5543% |
| Aligned-Linear-HLR -lex | 0.119907 | 0.000016 | 0.287826 | 0.535181 | -0.041558 | 0.975250 | 36.9300% |
| N-HLR -lex | 0.118903 | 0.000053 | 0.287354 | 0.540203 | 0.125079 | 0.976568 | 36.6777% |

Aligned-Linear 与 N-HLR 的表格值为三个种子的均值，标准差为种子间样本标准差。

## 5. 对 MAE 改善的描述性分解

以三个种子的均值计算：

1. 从原始 HLR -lex 到 Aligned-Linear-HLR -lex：

\[
0.128283-0.119907=0.008376.
\]

这部分改善发生在线性函数族不变的情况下，因此主要与损失函数、Adam、多轮 minibatch 训练、梯度裁剪和 Validation 选模有关。

2. 从 Aligned-Linear-HLR -lex 到 N-HLR -lex：

\[
0.119907-0.118903=0.001004.
\]

这部分是在训练流程已经对齐后，由四个 ReLU 隐藏单元带来的额外改善。

3. 从原始 HLR -lex 到 N-HLR -lex的总改善：

\[
0.128283-0.118903=0.009380.
\]

按照这一描述性分解，约 89% 的 MAE 改善出现在训练方法改变之后，约 11% 是对齐训练后加入非线性结构的额外改善。该比例用于描述当前实验中的差值构成，不应解释为严格的因果贡献率。

## 6. 结果解释

### 6.1 非线性具有小而稳定的额外贡献

N-HLR 在三个配对种子下都比 Aligned-Linear 获得约 0.001 的 Test MAE 改善，而且 Validation 上也得到一致排序。因此，结果支持四个 ReLU 隐藏单元确实提供了额外预测能力，改善不能完全由随机初始化或单次运行解释。

不过，这一额外收益远小于原始 HLR 与 Aligned-Linear 之间的差距。原报告中 N-HLR 相对 HLR 的大部分 MAE 优势，更可能来自损失尺度、优化器、多轮训练和 Validation 选模，而不是单独来自非线性结构。

### 6.2 新训练方式主要通过提高预测值降低 MAE

原始 HLR -lex 的平均 Test 预测为 0.962699，Aligned-Linear 提高到 0.975250，N-HLR 进一步提高到 0.976568。由于 Test 标签大量集中在回忆率上界，提高整体预测值可以显著降低高回忆率记录的绝对误差。这说明 MAE 改善不一定等价于所有回忆率区域的预测都变得更好。

### 6.3 不同指标存在权衡

Aligned-Linear 的 MAE 和 RMSE 明显优于原始 HLR，但 AUC 从 0.537459 降至 0.535181，半衰期 Spearman 从 0.160552 降至 -0.041558。它更好地拟合了总体回忆率 MAE，却削弱了记录级排序和半衰期排序。

N-HLR 相对 Aligned-Linear 不仅降低 MAE 和 RMSE，还将 AUC 提高到 0.540203，并将半衰期 Spearman 恢复到 0.125079。这表明非线性结构的作用不只表现为将预测整体上移，也保留了更多输入相关的排序信息。不过，N-HLR 的半衰期 Spearman 仍低于原始 HLR 的 0.160552，因此不能认为它在所有指标上都优于原始模型。

## 7. 实验限制

### 7.1 正则化不可完全等价

Aligned-Linear 的参数是一个线性系数向量，N-HLR 使用两层参数 \(W_1,W_2,b_2\)。即使两者都使用 `L2=1e-6`，两层网络仍可以在层间重新缩放参数：

\[
W_1\rightarrow cW_1,
\qquad
W_2\rightarrow W_2/c.
\]

该变换可能近似保持预测函数不变，却改变参数的 L2 范数。因此，相同的名义 L2 系数并不代表完全相同的函数级约束。本实验对齐了损失权重、优化器和名义正则系数，但剩余差异不能被严格解释为纯粹的非线性贡献。

### 7.2 随机种子数量有限

三个种子足以检查结果方向是否稳定，但不足以支持正式的统计显著性结论。后续若需要更强的统计结论，应增加重复次数，并对配对 MAE 差异报告置信区间。

### 7.3 结论依赖当前数据分布和主指标

Test 中大量标签位于回忆率上界，MAE 对这些记录具有很高权重。该结论适用于当前按行切分的数据和 MAE 评价目标，不一定推广到按用户隔离的测试集、低回忆率子集或真实调度收益。

## 8. 建议写入报告的结论

可在后续报告中采用以下表述：

> 为区分网络非线性与训练方法的影响，我们增加了一个与 N-HLR 使用相同损失、Adam、batch、训练轮数和 Validation 选模规则的线性对照模型，并在不含词元特征的输入上运行三个配对随机种子。原始 HLR -lex、对齐线性模型和 N-HLR 的 Test MAE 分别为 0.128283、0.119907 和 0.118903。由此可见，N-HLR 相对原始 HLR 的大部分 MAE 改善在保持线性结构、仅对齐训练方法后已经出现；四单元 ReLU 网络在此基础上仍带来平均 0.001004 的额外 MAE 改善，并且三个种子下方向一致。结果支持非线性结构具有小而稳定的额外贡献，但主要改善来自损失和优化训练规则的变化。由于两种参数化的正则化不能严格等价，且实验仅使用三个种子，这一分解应视为描述性证据，而非严格的因果贡献估计。

还应补充说明：

> 对齐线性模型虽然降低了 MAE，却降低了 AUC，并使半衰期 Spearman 变为负值；N-HLR 相对该线性模型改善了 MAE、AUC 和半衰期排序，但其半衰期 Spearman 仍低于原始 HLR。因此，模型优劣取决于评价目标，最低 MAE 不代表所有预测性质均得到改善。
